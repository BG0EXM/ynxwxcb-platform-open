# 伊宁县委宣传部部务工作平台 — 离线/内网部署保障说明

> 目标：平台可完全在**无互联网环境**（纯内网/政务隔离网）部署运行，不依赖任何在线资源。

## 一、结论

**平台已完全本地化，无需任何在线资源即可运行。**

经过全面排查，前端构建产物（dist/static）和后端 Go 程序均无对外部 CDN、在线字体、远程脚本、外部 API 的依赖。

## 二、资源本地化排查明细

### 1. 前端资源（构建后全部打包到 backend/static/）

| 资源类型 | 来源 | 状态 |
|---|---|---|
| Vue / Element Plus / Pinia / Router / Axios | npm 本地打包进 JS | ✅ 本地 |
| Element Plus 图标 | 内嵌为 SVG（628 处 svg） | ✅ 本地 |
| CSS 样式 | 全部本地 CSS 文件（17 个） | ✅ 本地 |
| 图片 url() | data URI（base64 内嵌） | ✅ 本地 |
| 字体 | 无 @font-face，走系统字体（微软雅黑等） | ✅ 本地 |
| favicon / 党徽 | public/ 和 src/assets/ 本地 PNG | ✅ 本地 |

### 2. 前端无外链确认

- index.html：仅引用 `/favicon.png`、`/assets/*.js`、`/assets/*.css`（全部同源本地）
- axios baseURL：`/api`（同源相对路径，经 Nginx 反代到后端）
- **无** `<script src="https://...">`、`<link href="https://...">` 外部标签
- **无** 动态创建远程 script/link 的代码
- **无** Web 字体下载（无 @font-face）

### 3. 构建产物中的链接说明（无需处理）

构建产物里能搜到 `http://` / `https://` 字样，但全部属于**不会触发网络请求**的内容：

- `http://www.w3.org/2000/svg` 等 → SVG/XML **命名空间标识符**（W3C 标准声明，浏览器不请求）
- `https://element-plus.org/...`、`https://vuejs.org/...` → 组件**源码注释里的文档链接**，仅存在于字符串中
- `http://localhost` → axios 代理配置文本

这些均不影响离线运行，无需清理。

### 4. 后端程序

- Go 程序为静态编译二进制（`CGO_ENABLED=0`），运行时不下载任何东西
- SQLite 为纯 Go 驱动（modernc.org/sqlite），无外部数据库服务
- **无** 对外部 HTTP API 的调用（代码中无 http.Get/Post 外部请求）

## 三、离线部署的注意事项

### 1. 部署机需要联网的场景（仅开发/构建阶段）

| 场景 | 是否需要联网 | 说明 |
|---|---|---|
| **服务器运行平台** | ❌ 不需要 | 直接上传编译好的二进制 + 静态文件即可 |
| 服务器上重新编译 Go | ✅ 需要 | 需下载 Go 依赖（或用本机构建后上传） |
| 服务器上重新构建前端 | ✅ 需要 | 需 npm 下载依赖（或本机构建后上传 dist） |

> **生产建议**：在联网的构建机上完成 `go build` 和 `npm run build`，将编译好的
> `ynxcb-server` 二进制（含静态资源）上传到内网服务器，**服务器全程无需联网**。

### 2. 二进制含前端资源说明

后端通过 `backend/static/` 目录提供前端页面，两种部署方式：

- **方式 A（推荐）**：将 `ynxcb-server` 二进制和 `static/` 目录一起上传，运行目录内需有 `static/` 子目录
- **方式 B（彻底单文件）**：将前端资源**嵌入**二进制（用 `go:embed`），实现单文件部署

当前实现为**方式 A**（static 目录跟随部署）。如需方式 B 可改造。

### 3. 系统字体依赖

平台未打包字体文件，依赖目标系统已安装的中文字体（微软雅黑 / 文泉驿 / Noto CJK）。
Debian 服务器若不装桌面环境，需确认客户端浏览器所在系统有中文字体即可（服务端不渲染前端字体，无此问题）。

## 四、离线验证清单

部署到内网后逐项验证：

```bash
# 1. 后端无外网请求（可关掉服务器外网测试）
# 服务器防火墙只开 80/443 和回环，平台功能应完全正常

# 2. 浏览器开发者工具 Network 面板
#    刷新登录页，确认所有请求都是本地资源（无灰色外网请求）

# 3. 检查字体加载
#    Network 面板 Filters → Font，应无任何字体请求（系统字体）

# 4. 验证各功能模块（收文/考勤/请假/公车/排班/报表）全部正常
```

## 五、未来改造方向（可选）

- **单文件嵌入**：用 `go:embed` 把 static/ 嵌入二进制，部署只需一个文件
- **离线字体**：如需统一字体显示，可下载开源字体（如思源黑体）本地化引用
- **离线依赖库**：前端依赖已本地打包；Go 依赖已在 go.sum 中锁定版本
