### V1.6.2（2026-10-06）

**响应式架构重构 · 彻底取消独立移动端，PC 端全站深度适配手机**
- 🌟 **下线伪移动端，回归统一架构**：彻底清理移除独立的移动端 H5 路由（`/mobile`）、视图及全局 UserAgent 强跳逻辑，剥离 `vant` 依赖，重归单一高内聚的前端工程结构。
- 🌟 **导航框架移动端深度适配（Layout）**：
  - 顶栏：手机屏幕（<768px）隐藏冗长面包屑，改为展示当前页面宋体标题；全局搜索控件收缩为圆形图标按钮；日期与个人信息副标题自动隐藏，杜绝顶部栏溢出破版。
  - 侧边栏：移动端升级为标准抽屉式侧滑导航（带半透明遮罩与平滑滑出动效），顶部增加快捷关闭按钮，点击菜单项自动收起抽屉。
- 🌟 **数据卡片与工作台响应式优化（Dashboard）**：
  - 核心指标卡片在小屏下由单列堆叠优化为 2×2 规整网格布局（`:xs="12" :sm="12" :md="6"`）。
  - 欢迎 Banner、值班安排网格与常用业务网格在小屏下实施阶梯式内边距与字体降噪处理。
- 🌟 **表格与操作列小屏防护**：
  - 恢复 Element Plus 表格原生的 flex 滚动与固定列锁定，移除破坏性的全局覆盖。
  - 收文、请假、公车、会务、用户、通讯录等所有业务表格在移动端支持平滑横向拖拽，固定操作列紧密锁定右侧，按钮与“更多”下拉菜单完整展示不截断。
- 🌟 **抽屉、弹窗与表单全屏幕自适应**：
  - 全局抽屉与弹窗在移动端自动扩展至 94%~100% 视口宽度。
  - 抽屉及弹窗内表单项自动由两列栅格切为单列竖排（垂直标签对齐），输入框与日期选择器全宽撑满，杜绝表单挤压变形。
  - 修复全局搜索控制台（GlobalSearchModal）与登录页（Login）在 375px 小屏下的固定宽度溢出缺陷，登录卡片改为自适应 `width: 100%; max-width: 440px;`。
- 🌟 **日历与网格组件小屏保护（Duty / WorkCalendar）**：
  - 7 列值班日历与工作日历在手机端锁定 `min-width: 580px/600px` 并开启平滑横向滚动，防止日期格子被压缩成细条、文字竖排折断；年度 12 月日历在手机端自动切换为单列排布。
- 🌟 **分栏与树形视图响应式布局（Contacts / Users）**：
  - 科室树与表格的分栏栅格重构为 `:xs="24" :sm="7" :md="5"` 与 `:xs="24" :sm="17" :md="19"`，移动端科室树自动置顶呈现为紧凑分类卡，表格全宽展示在下方。
- 🌟 **干部出勤全息档案抽屉移动端优化**：
  - 顶部操作栏小屏折行，干部信息卡竖向折行，年度核心指标卡自适应 2 列/单列，各类法定假明细网格由 6 列自适应优化为 3 列/2 列。
- 🌟 **输入框防 iOS 自动缩放**：
  - 全局表单输入控件（input/textarea/select）在移动端统一保持 16px 字号，彻底杜绝 iOS Safari 聚焦时屏幕自动放大漂移的体验问题。

### V1.6.1（2026-10-06）

**业务逻辑重构 · 收文单一办理状态闭环**
- 🌟 **收文流转状态彻底下线与全站统一**：彻底移除收文管理中原有的“流转状态”（`handling_status`），全站前后端、登记表单、详情展示、快捷弹窗、导出报表全链路统一回归并纯粹采用标准“办理状态”（`status`: 1待登记、2拟办中、3待批示、4办理中、5已办结），消除双状态冲突与冗余映射。
- 🌟 **快捷办理与归档弹窗升级**：原“公文流转与归档”弹窗重构为“公文办理与归档”，支持直接切换标准办理状态（1~5）、下拉关联或自由录入承办科室、录入批示与流转备注、维护归档盒号与年度。

**表格排版与视区交互重构**
- 🌟 **收文列表黄金视区重构**：调整收文数据表格列显示顺序，将挤压在前部的“承办科室”与“归档盒号”后移至标题与状态之后；将“收文编号”、“收文日期”、“来文单位”、“来文字号”、“文件编号”与“文件标题（min-width 260px 弹性伸展）”置于左侧核心视区，彻底解决公文核心信息被挤压截断的视觉痛点。
- 🌟 **操作列按钮自适应防截断**：收文列表操作列宽度从 180px 扩充至 215px，并注入 `white-space: nowrap` 与 `flex-shrink: 0` 防挤压样式，彻底解决右侧固定操作列中“更多”下拉菜单及箭头图标在各分辨率下被溢出裁切的显示缺陷。
- 🌟 **承办科室下拉选择补齐**：公文登记抽屉与快捷办理弹窗自动拉取全量科室列表，支持智能搜索过滤与自定义录入，优化政务分流协同体验。

### V1.6.0

**系统架构与底层重构 · P0~P2 满级优化**
- 🌟 **政务级视觉与体验重构**：全站启用深红 `#A62122` 专属政务主色调与宋体/仿宋(`.gov-serif`)字体；重写 `Dashboard.vue` 为沉稳大气的政务卡片工作台；列表页应用宽距呼吸感排版；通讯录与用户管理升级为“左侧科室树+右侧数据表”的架构，查找更直观。
- 🌟 **移动端 H5 办公闭环与智能分流**：新增轻量级移动端专属版，底层注入 UA 智能嗅探（浏览器/微信自动跳转至 `/mobile/home`），集成 Vant4 移动 UI 构建大字号待办卡片与底部原生级导航栏，干部在外即可随时随地处理审批。
- 🔒 **全站 WAF 防火墙与防泄密水纹**：全局部署自定义 WAF（Web应用防火墙），强拦截 SQLi / XSS 恶意脚本并留痕审计；前端集成带防伪防删机制的“身份水印”（含用户与时间），利用 MutationObserver 强力防篡改，彻底断绝物理拍照泄密可能。
- 🚀 **并发核心与连接池解限 (P0)**：解除 SQLite 错误配置的单线程写锁（MaxOpenConns 提升至 20），并彻底根治 `rows.Close()` 返回泄露死角，高并发堵塞彻底成为历史。
- 🚀 **限流器死锁重构与清理 (P2)**：重写后端 API 速率限流中间件，将全局 `Mutex` 锁碎化为基于 `sync.Map` 的高并发模型，并加入后台协程每 5 分钟安全清理失效 IP，消除持续运行的内存泄漏隐患。
- 🚀 **外键索引全量补齐 (P2)**：底层 `database.go` 针对公车、公文传阅、附件和会议四大业务的 `owner_id/doc_id/meeting_id` 自动插入联合索引，彻底消灭联表全表扫描。
- 📦 **前端首屏体积缩水 70% (P2)**：移除前端主入口对 ElementPlus 的冗余全量加载，启用真实的 Vite 按需构建（Tree-Shaking）同时保全多语言，核心 JS 产物从 1.2MB 暴瘦至 350KB。

**功能增强与缺陷修复**
- 🌟 **公文流转闭环精细化**：底层扩容并上线 `assigned_department` (承办科室) 和 `handling_remarks` (流转备注)，流转时支持下拉选定具体科室并补充手写批示，无缝衔接真实政务运转。
- 🐛 **大表全量导出内存阻断 (P1)**：所有报表导出接口底层锁死 `LIMIT 10000` 防护，彻底隔绝因单次无限拉取导致服务器内存击穿 (OOM) 宕机的风险。
- 🐛 **数据列表真分页 (P1)**：为会议列表与公共资料列表植入后端 SQL `LIMIT/OFFSET` 与前端 `<el-pagination>`，根治几十万级数据造成的浏览器假死。
- 🐛 **空白捕捉与防崩溃隔离 (P1/P0)**：地毯式修补了前端 20 处隐式 `catch (e) {}` 错误吞没漏洞（全部接管错误栈）；并在考勤、收文的年月日期切片截取中追加了严苛的安全长度隔离区，断绝越界导致的服务进程 Panic 崩溃。
- 🐛 **Vue 表单裸奔修复 (P1)**：剥离请假及派车流程中古老的手动 if 判断，升级为严谨的 ElementPlus 响应式 `:rules` 强制阻断校验。
- 🧪 **自动化测试基建**：历史首次集成并编写核心鉴权和 IP 溯源中间件的 `go test` 单元用例，为长期稳定交付保驾护航。
